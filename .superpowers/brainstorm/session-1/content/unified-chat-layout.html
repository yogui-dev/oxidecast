2. Las 3 Formas de Ver el Chat (Mi Recomendación Técnica)

Te recomiendo implementar un sistema híbrido que soporte los 3 escenarios según la cantidad de monitores que uses:

1. Panel Lateral Integrado (Dock)

El chat vive directamente en el costado derecho de OxideCast. No tapa los lienzos ni los controles y te permite leer todo desde la misma ventana central.

2. Ventana Desacoplable (Pop-out 2do Monitor)

Al hacer clic en ↗️ Desacoplar, Tauri abre una ventana secundaria independiente y ultraligera que puedes arrastrar a un segundo monitor, televisor o tablet.

3. Modo Ghost Overlay (1 Solo Monitor)

Si estás jugando en pantalla completa en un solo monitor, una ventana semitransparente flota sobre el juego con Click-through (los clics del ratón atraviesan el chat para no estorbar en el juego).

3. ¿Cómo prefieres que implementemos el Chat?

Selecciona tu alternativa preferida para incluirla en la arquitectura definitiva:

Panel Integrado + Ventana Desacoplable (Recomendada)

B

Ventana Secundaria Dedicada

El chat no ocupa espacio en la ventana principal; se abre como una ventana auxiliar separada lista para ubicar en tu segundo monitor.

C

Ghost Overlay sobre el Juego

Prioridad para setup de un solo monitor: chat flotante transparente encima del juego con soporte para que no capture los clics del mouse.
